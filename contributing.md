# Contributing

Thank you for your interest in contributing to this list!

## Guidelines

1. **Search existing entries** to avoid duplicates before adding a new deal.
2. **Follow the format**: `- [Name](url) - Description. **Value:** amount`
3. **Verify the deal** is currently active and available to at least one of: students, startups, or open source maintainers.
4. **Link directly** to the program or signup page, not the product homepage.
5. **Be accurate** with value estimates. Use the value of the highest tier available.
6. **Add to the correct category**. If unsure, pick the closest match.

## Adding a New Deal

1. Fork this repository.
2. Edit `README.md` and add your entry in the appropriate category, in alphabetical order.
3. Commit your changes with a clear message: `Add [Deal Name]`.
4. Open a pull request with a brief description of the deal and who it's for.

## Updating an Existing Deal

If a deal has changed (new URL, updated value, discontinued), please open a PR or issue.

## Quality Standards

- The deal must offer genuine, meaningful value (not just a generic free tier everyone gets).
- The URL must work and point to the relevant program page.
- The description must be concise and factual.
